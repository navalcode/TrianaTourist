# Design and contract

This repository is an existing Java coursework example. The shared portfolio direction is applied through readable commands, explicit results and honest evidence. GitHub retains its native typography/theme; no graphical UI, font, motion or generated runtime image is introduced.

Preserve Spanish error-envelope keys and successful DTOs. Status codes and headers follow the actual HTTP failure. Route/category update can keep its own name; ID lists reject duplicates independently of database state. Mutating multi-entity service operations share a transaction. No map, tracking, external image or production service is invented.

## Review path

English-first and Spanish README versions cover the same behavior, commands and limits. HTTP routes/statuses or model contracts precede implementation detail. Original names, public success shapes, seed data, notices and attribution remain. New regression fixtures are fictional. DESIGN is separate from agent instructions.

## Evidence and limits

Recorded tests are local JDK 17/macOS executions, with isolated Maven settings/cache; no new hosted CI is claimed. Existing toolchain pins remain. Persistence checks use isolated in-memory databases, never user data files. A successful demo does not establish authentication, deployment, concurrency safety or a supported production stack. See docs/verification.json and THIRD_PARTY.md.
